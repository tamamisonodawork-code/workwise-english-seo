# Workwise English v4

SEO/AEO-ready static site for Workwise English.

## Included

- Desktop and mobile hero image support with `<picture>`
- SEO-friendly image filenames and alt text
- Semantic HTML sections
- SEO title and meta description
- Open Graph / Twitter Card metadata
- WebApplication JSON-LD
- FAQPage JSON-LD
- FAQ section for AEO
- robots.txt
- sitemap.xml
- site.webmanifest
- Responsive desktop/mobile Hero redesign
- Fixed CTA button centering on mobile
- Manrope headings + Inter body/UI
- Improved line-height, spacing, and mobile readability
- localStorage progress saving
- Export / Import
- Text-to-Speech / Shadowing copy
- No voice upload promise
- App pages: Dashboard, Practice, Review, Progress, Notebook, Settings

## Deploy on Vercel

- Framework Preset: Other
- Build Command: leave blank
- Output Directory: leave blank

## Notes

Progress is saved in the user’s browser. Use Export / Import to back up or move learning history.
