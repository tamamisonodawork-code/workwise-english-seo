# Workwise English Latest LP Direction

## Core message

Workwise English is not another AI correction tool. It is a free browser-based app for practicing what to say in real North American workplace moments.

## What changed

- Hero now emphasizes:
  - Not another AI correction tool
  - Real workplace moments
  - Tone, feedback, and culture
  - Listen and say it aloud
- Hero headline changed to:
  - Correct is not enough.
  - Know what to say at work.
- Mobile order changed:
  - Hero image first
  - Then headline, copy, CTA, reassurance
- Main scenario categories updated:
  - Small Talk & Openings
  - Requests
  - Meetings
  - Disagreement
  - Clarifying Questions
  - Follow-ups
  - Soft Feedback
  - Feedback Response
- Removed Email & Chat and Interviews from main LP categories.
- Added learning-science loop:
  - Try first
  - Check feedback
  - Review later
  - Say it aloud
- Added original forgetting-curve style visual with brain badge.
- Added LP promise:
  - quick quizzes
  - own response input
  - check my response
  - model answer + explanation
  - North American culture notes
  - soft feedback and sandwich feedback
  - text-to-speech / shadowing
  - review queue
  - mistake notebook
- Added click-to-enlarge lightbox for informative LP illustrations.

## Phase 1 app promise

The app should not promise full AI correction. It should promise:
- learners write their own response
- they check and compare it against a work-ready model answer
- they read explanations
- they listen with text-to-speech
- they save useful phrases for review
